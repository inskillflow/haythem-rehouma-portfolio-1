```
assets/
├── images/          # Image files
│   ├── haythem-rehouma.jpg    # Profile photo #1 (Hero section)
│   └── haythem-rehouma-1.JPG  # Profile photo #2 (About section)
└── README.md        # This file
```

## Images

### Profile Photos
- **File 1**: `haythem-rehouma.jpg`
  - **Usage**: Hero section (main landing image)
  - **Style**: Dynamic, energetic pose
  
- **File 2**: `haythem-rehouma-1.JPG`
  - **Usage**: About section (professional portrait)
  - **Style**: Professional, close-up portrait

- **Recommended size**: Minimum 800x800px for both
- **Format**: JPG, PNG, or WebP
- **Aspect ratio**: Square or portrait orientation works best

### Adding More Images

If you want to add more images (project screenshots, logos, etc.):

1. Create subdirectories as needed (e.g., `images/projects/`)
2. Use descriptive filenames (e.g., `project-copilot-platform.jpg`)
3. Optimize images before uploading:
   - Use tools like [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/)
   - Recommended max size: 500KB per image
   - Use WebP format when possible for better performance

### Image Optimization Tips

- **Profile photo**: 800x800px, 80% quality, ~100-200KB
- **Project images**: 1200x800px, 80% quality, ~200-300KB
- **Background images**: 1920x1080px, 70% quality, ~300-400KB

## Adding New Asset Types

If you need to add other assets:
