## Guides Détaillés vs Express

### Quand Utiliser Quoi?

**Guides Détaillés (04 & 05):**
- Vous apprenez pour la première fois
- Vous êtes étudiant dans le cours
- Vous voulez tout comprendre
- Vous avez du temps

**Guides Express (09 & 10):**
- Vous connaissez déjà Git
- Vous voulez juste déployer vite
- Vous cherchez un aide-mémoire
- Vous êtes pressé

**Comparaison:**

| Aspect | Détaillé | Express |
|--------|----------|---------|
| Longueur | 600-800 lignes | 100-150 lignes |
| Temps | 20-30 min | 10 min |
| Détails | Complets | Essentiels |
| Diagrammes | Multiples | Aucun |
| Exercices | Oui | Non |
| Troubleshooting | Détaillé | Basique |
